# Installation

Install the difyflow-helper directory itself as the skill root. Do not install the DifyFlow-Helper repository root.

The installable root is `difyflow-helper/`, with `SKILL.md` directly inside it. The repository root and `dev_docs/` are development materials, not part of the installed skill.

## Targets

- Primary: Codex CLI.
- Secondary: Claude Code.
- Other agents: best-effort only.

Installation paths and commands may change by agent version. If the exact current command is uncertain, follow the current official documentation for that agent and select the `difyflow-helper/` directory itself.

The installed package contains reusable agent instructions, references, assets, and safe helpers only. It contains no user Flow, debug, report, generated artifact, or other runtime data.
