# Report Templates

Reports are optional. Default debug and Flow analysis output is chat. Use a formal report only when the user asks for one, wants a shareable artifact, or confirms file output for a complex case.

- `debug-report-classic.md`: optional structure for Scene4 debugging reports.
- `flow-analysis-report.md`: optional structure for Scene6 Flow analysis reports.

Templates are adaptable starting points, not mandatory rigid schemas. Remove irrelevant sections and keep the report proportional to the case. Do not expand this directory into a large output-template library.

Analysis reports require a user request or confirmation. Write confirmed reports under the current case `generate/reports/`.

This report needs to support both Chinese and English. Based on the primary language used by the user, the language to be output will be determined. If it is impossible to make a precise judgment, the user should be consulted to determine which language to output.
