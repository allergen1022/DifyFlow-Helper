# Report Templates

Reports are optional. Default debug and Flow analysis output is chat. Create a report when the user requests one.

- `debug-report-classic.md`: optional structure for Scene4 debugging reports.
- `flow-analysis-report.md`: optional structure for Scene6 Flow analysis reports.

Templates are adaptable starting points, not mandatory rigid schemas. Remove irrelevant sections and keep the report proportional to the case. Do not expand this directory into a large output-template library.

Write requested reports under the current workspace's `generate/reports/` directory. The templates are optional starting points, not required formats.

Use the language of the user's request or supplied material. Ask about language only when the intended audience or deliverable makes it consequential and context does not resolve it.
