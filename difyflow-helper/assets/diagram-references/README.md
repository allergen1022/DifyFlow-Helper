# Diagram References

Use this folder for agent-facing style notes, method examples, and rendering conventions. Keep user-specific reference diagrams in the user's current case folder.

Before generating, determine how the diagram will be used: Word, PPT, Markdown, HTML, technical review, delivery, or display. Support Mermaid, JavaScript, SVG, HTML, pure image, and text-only outputs when appropriate.

Read only the relevant method folder and `style-notes/default-style.md`. These references are optional and must not become a user input requirement.
