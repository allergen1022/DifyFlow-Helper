# Default Diagram Style

Use these defaults only when the user has not specified a style and accepts a first draft:

- Use body text of at least 20px for rendered visual formats.
- Make title text larger than body text.
- Keep hierarchy and flow direction clear.
- Use minimal decoration and restrained colors.
- Avoid overly dense diagrams; split or simplify when readability suffers.
- Distinguish important node categories consistently when possible.
