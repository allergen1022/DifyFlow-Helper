# Reference Flows

This folder may contain minimal Dify Flow YAML/YML examples for agent reference (or remain empty, except for this README.md).

These examples are not user case files. Do not place real user Flows here. Do not treat any file here as the current official Dify import/export standard unless current Dify documentation has been verified online.

Before generating complete importable YAML or claiming exact current DSL schema, verify current Dify behavior online using official or primary sources.

User-provided reference Flows should remain in the user's current case folder, for example:

```text
D:/case/reference.yml
D:/projects/case/old-flow.yml
```
