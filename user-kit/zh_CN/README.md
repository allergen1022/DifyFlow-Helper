# DifyFlow Helper 用户材料包

这个目录提供用于 Dify Flow 工作的模板、示例和绘图参考。它不是 Agent Skill。

## 目录

- `templates/` 可选的轻量输入模板。
- `examples/` 已填写的脱敏示例。
- `reference-flows/` 可共享的参考 Flow。
- `diagram-kit/` 绘图方法和样式参考。
- `quick-start.md` 最短使用说明。

模板不要求完整填写。用户也可以直接提供现有文件、聊天内容、错误信息或原始面板内容。

## 使用约定

真实工作放在用户自己的 case 目录。生成文件只在用户要求或确认后写入 case 下的 `generate/`。不要把密钥、Token、Cookie、授权头、签名 URL、私有数据或生产日志放入共享材料。
