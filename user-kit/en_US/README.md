# DifyFlow Helper User Kit

This directory contains optional templates, examples, and diagram references for Dify Flow work. It is not an Agent Skill.

## Contents

- `templates/` lightweight input templates.
- `examples/` completed sanitized examples.
- `reference-flows/` reusable shared Flow references.
- `diagram-kit/` diagram methods and style references.
- `quick-start.md` shortest usage guide.

Templates do not need to be completed in full. Users may also provide existing files, chat content, error messages, or raw panel output directly.

## Usage rules

Keep real work in the user's case folder. Write generated files under the case `generate/` only after the user requests or confirms file output. Do not put keys, tokens, cookies, authorization headers, signed URLs, private data, or production logs in shared materials.
