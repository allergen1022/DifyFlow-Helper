# DifyFlow Helper User Kit

Choose a language package before copying materials into a case folder:

- [`en_US/`](./en_US/) English materials.
- [`zh_CN/`](./zh_CN/) Simplified Chinese materials.

`user-kit/` is a reference package. It is not an Agent Skill and must not be installed as one. Install only [`difyflow-helper/`](../difyflow-helper/).

The locale packages use the same directory structure and cover the same scenarios.
