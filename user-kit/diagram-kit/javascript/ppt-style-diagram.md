# PPT-Style JS/SVG Diagram / PPT 风格 JS/SVG 图

使用固定 16:9 画布或可缩放 `viewBox`，以简单卡片、连线和有限颜色构建。 / Use a fixed 16:9 canvas or scalable `viewBox` with simple cards, connectors, and limited colors.

- 标题 ≥ 28px，正文 ≥ 20px。 / Title ≥ 28px; body ≥ 20px.
- 一页节点过多时拆成 overview/detail。 / Split crowded content into overview/detail views.
- 可生成独立 SVG，或在用户要求时生成包含 SVG 的 HTML。 / Generate standalone SVG, or HTML containing SVG when requested.
- 不强制使用第三方库；如使用必须列出依赖。 / Do not require a third-party library; list it if used.
