# JavaScript/SVG Basic Approach / JavaScript/SVG 基础方法

JavaScript 生成 SVG 适合精确布局、统一样式以及导出到 PPT/Word。 / JavaScript-generated SVG is useful for precise layout, consistent styling, and PPT/Word export.

- 只有用户明确要求 JS/SVG 输出时才生成可执行代码。 / Generate executable code only when JS/SVG output is explicitly requested.
- 简单 SVG 可使用浏览器原生 DOM API，不强制安装依赖。 / Simple SVG may use browser DOM APIs without dependencies.
- 如果生成 Node.js 脚本，应说明 Node.js 版本和依赖。 / For Node.js scripts, state runtime and dependencies.
- 文件输出前确认，并写到当前 case 的 `generate/diagrams/javascript/` 或 `generate/diagrams/svg/`。 / Confirm file output and use the current case generate folders.
