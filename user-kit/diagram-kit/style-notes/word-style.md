# Word Diagram Style / Word 绘图样式

- 根据图宽选择纵向或横向页面。 / Choose portrait or landscape based on width.
- 在文档缩放下仍应可读，标签保持简短。 / Keep labels concise and readable at document scale.
- 避免过宽；复杂图拆成多张。 / Avoid excessive width; split complex diagrams.
- 需要文件时优先 SVG，兼容性要求高时使用 PNG。 / Prefer SVG when possible, or PNG for broad compatibility.
