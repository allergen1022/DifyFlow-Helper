# HTML Diagram Style / HTML 绘图样式

- 使用响应式布局并允许横向滚动。 / Use responsive layout and allow horizontal scrolling.
- 使用 CSS 管理间距、字号和对比度。 / Use CSS for spacing, typography, and contrast.
- 除非明确要求，不加入复杂交互。 / Avoid heavy interaction unless requested.
- 确保可在现代浏览器预览。 / Support preview in modern browsers.
- 不在 HTML 中嵌入秘密或私有数据。 / Do not embed secrets or private data.
