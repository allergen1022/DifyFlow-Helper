# Default Diagram Style / 默认绘图样式

中文：未指定样式且用户接受初稿时，使用以下默认值。English: Use these defaults when no style is specified and the user accepts a first draft.

- 内容双语时保持简短，优先业务可读性。 / Keep bilingual content concise and business-friendly.
- 标题明显大于正文。 / Make the title clearly larger than body text.
- 视觉成品正文不小于 20px。 / Use body text of at least 20px in visual artifacts.
- 使用简单矩形或圆角矩形。 / Use simple rectangular or rounded boxes.
- 避免装饰过度和无意义图标。 / Avoid excessive decoration and meaningless icons.
- 优先从左到右或从上到下的清晰流向。 / Prefer a clear left-to-right or top-to-bottom flow.
- 优先显示节点名称，仅在必要时显示节点 id。 / Show node names first; use node ids only when necessary.
- 只在有帮助时显示关键输入/输出。 / Show key inputs/outputs only when useful.
- 使用克制的颜色：中性背景、一个主色、少量强调色。 / Use restrained colors: neutral background, one primary color, limited accents.
- 不显示密钥、token、签名/私有 URL 或私有值。 / Never expose secrets, tokens, signed/private URLs, or private values.
- Word/PPT 场景优先保证导出后的可读性；过密时拆分概览和详情。 / For Word/PPT, prioritize post-export readability and split crowded content into overview/detail views.
