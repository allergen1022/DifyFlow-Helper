# PPT Diagram Style / PPT 绘图样式

- 适配 16:9 幻灯片。 / Design for 16:9 slides.
- 标题不小于 28px，正文不小于 20px。 / Use titles at least 28px and body text at least 20px.
- 每页控制节点数量。 / Limit node count per slide.
- 复杂内容拆分为概览页和详情页。 / Split complex content into overview and detail slides.
- 使用简单图形和有限颜色。 / Use simple shapes and limited colors.
