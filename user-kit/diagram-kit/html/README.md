# HTML Diagram Examples / HTML 绘图示例

中文：HTML 图示例是可选的，当前目录故意保持最小。HTML 适合浏览器预览或内部展示页面。

English: HTML diagram examples are optional; this directory is intentionally minimal. HTML is useful for browser previews and internal display pages.

即使作者尚未提供 HTML 示例，agent 仍可在用户明确请求时，根据需求和 `../style-notes/default-style.md` 生成 HTML。 / Even without maintained examples, the agent may generate HTML on explicit request using the user's requirements and default style notes.

生成时应说明依赖、避免嵌入私有数据，并在写文件前确认。 / State dependencies, avoid private data, and confirm before writing files.
