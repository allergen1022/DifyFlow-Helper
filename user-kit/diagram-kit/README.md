# Diagram Kit / 绘图材料包

中文：此目录是可选的用户可见、agent 可读取的绘图参考。你可以维护自己的参考图、样式说明和生成方法。

English: This optional directory contains user-visible, agent-readable diagram references. Maintain your own reference diagrams, style notes, and generation approaches here.

生成前应说明图的用途：Word、PPT、Markdown、HTML、技术评审、交付文档或展示/分享。 / Before generation, state the usage: Word, PPT, Markdown, HTML, technical review, delivery, or display/share.

常见输出包括 Mermaid、JavaScript/SVG、PNG、HTML 或纯文本大纲。 / Typical outputs include Mermaid, JavaScript/SVG, PNG, HTML, or text-only outlines.

如果没有指定样式，使用 `style-notes/default-style.md`。用户专用参考图可放在当前 case，无需放入共享 kit。 / If no style is specified, use `style-notes/default-style.md`. Case-specific references may remain in the current case.

图文件通常在用户确认后写入当前 case 的 `generate/diagrams/`。 / Diagram files normally go under the current case `generate/diagrams/` after confirmation.
