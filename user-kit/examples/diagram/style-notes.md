# PPT Style Example / PPT 样式示例

- 用途 / Usage: 16:9 PPT.
- 标题 / Title: 28px or larger / 不小于 28px.
- 正文 / Body: 20px or larger / 不小于 20px.
- 图形 / Shapes: simple rounded boxes / 简单圆角矩形.
- 颜色 / Colors: one primary, one accent, neutral background / 一主色、一强调色、中性背景.
- 布局 / Layout: left to right; Horizontal or vertical; split overview/detail if crowded / 从左到右；横向还是纵向；过密时拆分概览与详情.
- 安全 / Safety: show no secret values or private URLs / 不显示密钥或私有 URL.
