# Reference Flows / 参考 Flow

中文：此目录是可选的用户/团队共享参考 Flow 库。作者、用户或团队可以放入经过脱敏、计划长期维护的参考 Flow。

English: This optional folder is a shared user/team reference Flow library. Authors, users, or teams may add sanitized references intended for ongoing maintenance.

私有、业务专用或仅与单个 case 有关的 Flow 应保留在当前 case 文件夹，不要提交到共享库。

Keep private, business-specific, or case-specific Flows in the current case folder rather than committing them to this shared library.

不要包含真实 API key、token、凭据、authorization header、cookie、签名 URL、私有 bucket URL 或生产数据。 / Do not include real keys, tokens, credentials, authorization headers, cookies, signed URLs, private bucket URLs, or production data.

Dify DSL、导入和导出格式可能变化。Agent 在声称文件可导入或生成完整可导入 YAML 前，必须在线核验当前 Dify 官方或主要来源。

Dify DSL/import/export behavior may change. Before claiming importability or generating complete importable YAML, the agent must verify current Dify official or primary sources online.
